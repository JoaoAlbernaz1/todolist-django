Sobre o Projeto

Um gerenciador de tarefas moderno e funcional desenvolvido com Django e Bootstrap

Visão Geral do Projeto

Este projeto é um sistema completo de gerenciamento de tarefas que demonstra o uso prático do framework Django para desenvolvimento web. O sistema permite aos usuários criar, editar, visualizar e excluir tarefas de forma intuitiva e eficiente.

O projeto foi desenvolvido seguindo as melhores práticas de desenvolvimento web, incluindo uma arquitetura MVC (Model-View-Controller), interface responsiva e experiência do usuário otimizada.

Tecnologias Backend
  • Django 4.x: Framework web Python
  • SQLite: Banco de dados relacional
  • Python 3.x: Linguagem de programação
  • Django ORM: Mapeamento objeto-relacional
Tecnologias Frontend
  • Bootstrap 5: Framework CSS responsivo
  • Bootstrap Icons: Biblioteca de ícones
  • HTML5: Linguagem de marcação
  • JavaScript: Interatividade do cliente

Funcionalidades Implementadas

Gerenciamento de Tarefas
  • Criar novas tarefas com título, descrição e prioridade
  • Editar tarefas existentes
  • Excluir tarefas com confirmação
  • Marcar tarefas como concluídas
Recursos Avançados
  • Sistema de prioridades (Baixa, Média, Alta)
  • Status de tarefas (Pendente, Em Progresso, Concluída)
  • Data de vencimento para tarefas
  • Interface responsiva e moderna

Conceitos Django Aplicados

Models

Definição da estrutura do banco de dados com campos, validações e relacionamentos.

Views

Lógica de negócio que processa requisições e retorna respostas apropriadas.

Templates

Interface do usuário com sistema de templates Django e Bootstrap.

URLs

Mapeamento de URLs para views específicas do sistema.

Forms

Formulários Django para validação e processamento de dados.

HTTP Methods

Uso de GET e POST para diferentes operações no sistema.

Informações de Desenvolvimento

Estrutura do Projeto
  • todolist/ - Configurações principais do Django
  • tasks/ - Aplicação principal de tarefas
  • templates/ - Templates HTML
  • migrations/ - Migrações do banco de dados
Como Executar
python manage.py runserver

Acesse http://localhost:8000 no seu navegador.
